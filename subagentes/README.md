- [Revisor SDD Backend](../.opencode/agents/backend-revisor-sdd.md) — Alineación entre Constitución propia, AGENTS, spec, plan y task de Backend.

- [Revisor de calidad Backend](../.opencode/agents/backend-revisor-calidad.md) — Requisitos verificables, modularidad, mantenibilidad, logging y pruebas futuras.
